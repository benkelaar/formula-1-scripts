# Flag asset provenance

## Current country flags

The 4×3 SVG files named with ISO country codes are an unmodified subset of
`lipis/flag-icons` version 7.6.0:

- Source: https://github.com/lipis/flag-icons/tree/v7.6.0/flags/4x3
- License: MIT; preserved in `LICENSE.flag-icons.txt`.
- Original filenames are unchanged.

## Historical Rhodesian flag

`rhodesia.svg` is the 2:3 rendition of the Flag of Rhodesia (1968–1979):

- Source: https://commons.wikimedia.org/wiki/File:Flag_of_Rhodesia_(1968%E2%80%931979,_3-2).svg
- Original filename: `Flag_of_Rhodesia_(1968–1979,_3-2).svg`.
- Copyright status: public domain, as documented on the source page for the
  underlying United Kingdom government work.

## Fallback

`unknown.svg` is original project artwork released under the repository's MIT
license.

Exact file SHA-256 values are recorded in `assets/manifest.json` and validated
before the identity reference dataset is published.
